# README 与知识图的设计说明

## 项目故事

- 读者：外贸企业负责人、运营人员和建站服务者。
- 一句话价值：先了解业务，再检查或规划网站技术，把 SEO、询盘和运营接起来。
- 可检查的实际材料：现有 Skill、八大模块、32 组知识点思维导图、家具新站教学案例、CDN 配置模板。
- 第一次成功操作：安装 Skill，输入网址做公开网页诊断，或发起新站业务访谈。
- 视觉主题：技术选型手册，以中心主题、八个模块和知识点编号组织信息。

## 视觉规则

- 背景 `#f5f7f3`，正文 `#183139`，主色 `#176d64`，辅助色 `#375f96`，说明文字 `#546c73`。
- 使用系统中文字体，不加载远程字体；标题、说明、编号分级。
- 细连接线、少量圆角、无装饰动画；图本身就是项目的证据材料。
- README 使用可编辑的静态 SVG 总览，正文保留为 Markdown，命令可以复制。
- 完整 32 组知识点导图作为单独的大图下载，README 展示八大模块概览，详细解释在 HTML / Markdown 中。
- 不把 32 个细节点压缩进 README 首屏；手机可直接阅读逐点解释。

## 重新生成

```bash
python3 scripts/build_maps.py
```

数据源是 `assets/knowledge-tree.json`。构建脚本只使用 Python 标准库，输出 SVG、离线 HTML 与 Markdown；PNG 为从已生成 SVG 导出的交付图片。

结构：中心主题 → 8 大模块 → 每个模块 4 组知识点，共 32 组。共 41 个节点，分为主题、模块、知识点三层，直接呈现业务模块与知识点的关系。
